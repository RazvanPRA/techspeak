# AGENTS.md (server)

Project rules live in `../.claude/CLAUDE.md` and `../.claude/SPEC.md`; read those first.

- NestJS 12 is newer than most training data: https://docs.nestjs.com/llms.txt indexes its docs.
- ESM project: relative imports end in `.js`, use `import.meta.dirname` (no `__dirname`).
- Tests run on Vitest (`vi.fn()`, not `jest.fn()`): `yarn test` runs the `unit` (src/**/*.spec.ts)
  and `e2e` (test/**/*.e2e-spec.ts) projects. e2e uses fakes for Azure and the database.
- Prisma 7: the client is generated into `src/generated/prisma` (git-ignored) on `yarn install`;
  the datasource URL is in `prisma.config.ts`.
- Free only: no paid APIs. Azure Speech is the F0 tier; feedback is rule-based.
- `src/content/decks/*.json` is generated by `yarn build:seeds` in `app/`; do not edit it by hand.
